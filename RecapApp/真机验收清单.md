# RecapApp 真机验收清单

> 版本：0.8.0 ｜ Fun-ASR + SpeechAnalyzer 资源安装

## 环境

- [ ] iPhone（建议 iOS 26 + Apple Intelligence，便于测 SpeechAnalyzer）
- [ ] Xcode 打开 `RecapApp/RecapApp.xcodeproj`，Scheme `RecapApp`，真机 Run
- [ ] 网络可用（DeepSeek / 阿里百炼；火山可选）

## 1. 设置与凭证

- [ ] 首页右上角齿轮 → 设置
- [ ] 保存 DeepSeek API Key → 显示「已配置」
- [ ] 保存阿里百炼 API Key（Fun-ASR）→ 显示「已配置」
- [ ] （可选）保存火山 App ID + Access Token → 显示「已配置」
- [ ] 引擎偏好：先选「自动」
- [ ] 设置 → 冒烟测试 →「跑冒烟」→ 流式纪要 + 待办出现

## 2. 列表与种子数据

- [ ] 首页可见种子会议「周会·产品评审」
- [ ] 点进 → 摘要 / 待办 / 逐字稿可切换
- [ ] 待办「确认客户报价」为低置信灰显，点「确认」后恢复
- [ ] 勾选待办可切换「已分发」态

## 3. LIVE 录音转写

- [ ] 底部录音 FAB → 授权麦克风
- [ ] 顶栏计时走动；底栏显示「正在收音」而非「演示字幕」
- [ ] 说话后出现实时字幕（SpeechAnalyzer / Fun-ASR / 火山，视偏好）
- [ ] 首次选 SpeechAnalyzer：允许下载中文资源后出字
- [ ] 若端侧不可用且无 Fun/火山凭证 → **错误态 +「重试」**，不得自动出现演示剧本
- [ ] DEBUG：错误态可点「改用演示字幕（DEBUG）」才出现演示台词
- [ ] 录音中来电/其他 App 抢音频结束后，应恢复收音或明确「音频被中断」提示（非无声假录音）
- [ ] 录音中锁屏一段时间，解锁后计时与字幕仍正常（idle timer 已禁用）

### 引擎矩阵（按设置偏好抽测）

| 偏好 | 预期 |
|---|---|
| 自动 | SpeechAnalyzer → Fun-ASR → 火山；全失败则错误态（非自动演示） |
| SpeechAnalyzer | 不支持机型 / 无中文资源应失败并提示重试 |
| Fun-ASR | 需百炼 Key；模拟器也可（纯 WebSocket） |
| 火山 | 需凭证；模拟器也可（纯 WebSocket） |

## 4. 结束 → 纪要管线

- [ ] 点「结束」→ 进入「正在整理…」
- [ ] 已配置**当前服务模式可用**的大模型 Key（BYOK 任意供应商或会员云）：流式 TL;DR + 待办
- [ ] 仅配非 DeepSeek 的 BYOK（如通义）也应出真纪要，不得因「不是 DeepSeek」掉进演示
- [ ] 无可用密钥：空纪要 + 明确「未配置可用的大模型密钥」，**不得**注入演示待办「出移动端评审方案」
- [ ] 回到首页，该会议出现在「今天」，时长非「进行中」

## 5. 问 Recap / 技能

- [ ] 会中或会后打开「问 Recap」，提问「总结」→ 基于转写回答（有可用密钥）
- [ ] 「技能」→ 任选一项 → 有密钥时流式生成；无密钥时失败提示（非演示假成功）

## 6. 回归与边界

- [ ] 杀进程重开 → 会议与待办仍在（SwiftData）
- [ ] LIVE 中产生 ≥2 条字幕后杀进程 → 重开同一会议，字幕仍在且可续录
- [ ] LIVE 中返回列表再进入 → 字幕仍在（检查点落盘）
- [ ] LIVE 真录后 `Meeting.audioPath` 有文件；REVIEW 顶栏「重转」可更新逐字稿
- [ ] REVIEW 顶栏「区分说话人」（或会后自动）→ 逐字稿出现「发言人1/2…」；首次需下载 SpeakerKit 模型
- [ ] Keychain 凭证仍在（清除 App 后除外）
- [ ] 模拟器：UI / 列表 / 设置 / 冒烟可用；LIVE 失败为错误态，DEBUG 可显式演示

## 通过标准

1. 真机至少一条路径：**录音 → 真实 ASR 字幕 → 云端纪要+待办 → 持久化可见**
2. 无凭证时失败可理解、不崩溃、**不伪造成功**
3. 模拟器 Debug 构建通过（`generic/platform=iOS Simulator`）
