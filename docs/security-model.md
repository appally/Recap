# 安全模型（Security Model）

> 本页面向用户与审计者：说清「你的数据在哪、谁能看到、自定义能力的安全边界」。
> 对应战略：《开放化战略与架构重构建议-2026-09》信任层；实现 plans/056/058/059/060。

## 你的数据在哪

| 数据 | 存放位置 | 何时离开本机 |
|---|---|---|
| 会议音频 / 转写 / 纪要 / 待办 / 人物与声纹 | 本机（SwiftData + App 容器文件，声纹默认排除 iCloud 备份） | 仅当你显式选择云端 ASR / LLM 或导出 |
| API Key（各厂商 / 托管凭证） | 本机 Keychain | 永不（不进 UserDefaults、不进日志、不进导出物、不进开源仓库） |
| 自备密钥模式（BYOK）的转写与纪要文本 | — | 发往**你自己配置**的端点（保存时明示 host） |
| 官方托管模式（免费档/Pro）的转写与纪要文本 | — | 发往 Recap 网关（recap.manymind.chat）→ 中转出模型请求；网关不落盘用户内容 |
| 声纹特征 | 本机 | **永不导出**（导出/备份默认排除） |

## 托管凭证模型（plan 056）

- 客户端不持有任何中转共享密钥；托管 LLM 出口 = `/v1/issue` 签发的短期 HMAC relay token（TTL 与签发一致，免费档 LLM 15 分钟封顶）→ 经网关 `/v1/relay` 代理转发。
- 真实中转 Key 只存 Cloudflare Workers secret；网关强制改写 `model`，客户端不能选择托管模型。
- 与既有阿里临时 token 同信任模型：token TTL 内不限次；计量按 `/v1/issue`。

## 自定义能力的边界

| 能力 | 能做什么 | 不能做什么 |
|---|---|---|
| 自定义 LLM 端点（059） | 你填的 baseURL 收到你发去的转写/纪要文本 | 收不到 Keychain 里的其它 Key；导出的「供应商配方」JSON 不含 Key |
| 自定义 SKILL.md（060） | 声明 system prompt / 工具白名单 / 步数 | **导入即同意时刻**：确认页列能力清单，外部技能默认按只读降权；codec 层硬禁 `create_reminders` / `revise_minutes` / `run_skill` 嵌套 |
| 自定义 ASR 端点（061） | 会后重转/导入路径的音频发往你填的端点 | 不参与 LIVE 实时转写；启用前必须通过连接测试 |

## 威胁模型摘要

- **恶意 SKILL.md / 配方文件**：是不可信输入。缓解：导入确认页（能力清单 + 默认降权）、工具白名单硬边界、写操作 HITL 审批（Agent 内核既有纪律）、forbiddenTools 硬禁。
- **提取二进制**：无共享密钥可提取（056 起）；各密钥仅在用户自己的 Keychain。
- **网关滥用**：/v1/issue 有 per-IP 限流与设备桶；/v1/relay 仅认 HMAC token；阈值参数已外置为 Workers vars，可随时收紧不发版。
- **仓库泄露**：CI 跑 gitleaks 全历史扫描；开发凭证存放于仓库外（`~/.recap/`），开源前检查单包含逐一核对。

## 已知限制（诚实清单）

- Agent 传输层（Ask/深度调研）暂无 401 重签：免费档 15 分钟 token 过期时长任务会如实失败（Provider 侧纪要管线已有重签）。
- 声纹、人物关系数据的删除跟随「账户删除」（App 内删除 + 网关桶清除）；不提供云端副本（因为没有云端副本）。
- MCP server（规划中）为只读、运行在**你自己的机器**上、读**你自己的**开放工作区目录。
